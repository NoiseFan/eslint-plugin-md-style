# Space Around Quot

规范 Markdown 文本中成对引号的内外空格。

## 规则详情

`space-around-quot` 检查同一个文本节点内成对的中文引号 `“”`、`‘’` 和半角引号 `""`、`''`。引号与内容之间不能有水平空格。引号内只有 CJK 字符时使用 `“”`；只有拉丁字母时使用半角引号（原有的单引号或双引号均可）。混合语言和无文字内容保留原引号。默认情况下，半角引号与相邻文字之间恰好有一个空格；全角引号与相邻文字之间没有空格。按照本文示例的中文行文习惯，汉字后接中文开引号时保留一个空格。引号紧邻全角标点、成对标点或其他引号时不加空格；闭引号后接半角逗号、句号等标点时也不加空格。

规则检查段落、标题、列表项和链接标签中解析为文本节点的内容。它不会跨文本节点配对引号。

## 选项

规则接受一个对象选项：

```json
{
  "halfwidth": "always",
  "fullwidth": "never"
}
```

`halfwidth` 和 `fullwidth` 的值均可为 `"always"`（外侧需要一个普通空格）或 `"never"`（外侧不留空格）。默认值分别为 `"always"` 和 `"never"`。这些选项不影响引号内部空格和紧邻标点的处理。`fullwidth: "never"` 时，汉字后接中文开引号仍保留一个空格。

## 正确示例

```md
他说 “你好”，然后说 "hello world"。
It's fine to say 'hello'.
```

配置 `{ "halfwidth": "never" }` 时：

```md
"hello"world
```

配置 `{ "fullwidth": "always" }` 时：

```md
他说 “你好” 然后走了
```

## 错误示例

```md
他说“ 你好 ”，然后说"hello world"。
He said" hello "and left.
他说 "你好"。
```

## 自动修复

此规则支持自动修复。修复器删除引号内部的水平空格，在引号外侧插入、删除或压缩水平空格，并在纯中文或纯英文内容需要时替换引号字符。上面的第一行会修复为：

```md
他说 “你好”，然后说 "hello world"。
```

修复不会跨越换行，也不会修改引号之外的正文。

## 忽略的上下文

围栏代码块、行内代码、HTML 注释和 YAML frontmatter 不作为文本节点检查。词中的撇号（如 `It's`）不会识别为引号。转义引号和无法在同一个文本节点内配对的引号也不会修改。

## 不适用场景

如果项目使用不同的引号空格排版约定，可以关闭此规则。
